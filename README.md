# PainOwl Precision Instrument UI Prototype

This repository contains a lightweight static prototype of the PainOwl light-mode redesign, with a focus on click reliability and interaction coverage.

## Included

- Warm neutral light content area with dark zinc sidebar
- Burnt-orange accent system and score-status palette
- Radar, Tracked, and Startup Profile pages
- Interactive score rings with animated load
- Clickable cards that open a Validation Brief modal
- Working Scan modal, tab switching, segmented control, and toasts
- Track / dismiss / archive actions with visible state updates

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

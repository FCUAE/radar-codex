# PainOwl Precision Instrument UI Prototype

This repository now includes a lightweight static prototype of the PainOwl light-mode redesign, implementing:

- Warm neutral light content area with dark zinc sidebar.
- Burnt-orange accent system and score-status palette.
- Reusable score ring SVG component with animated stroke and counter.
- Radar, Tracked, and Startup Profile screen slices using the new component language.
- Density-first card treatments with title-first content hierarchy and reduced body copy.

## Run locally

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
